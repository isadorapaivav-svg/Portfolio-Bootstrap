# Portfólio Pessoal - Bootstrap 5

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática do curso de Bootstrap 5 da plataforma Cursa.

O objetivo é aplicar os principais conceitos apresentados durante as aulas, criando uma página de portfólio pessoal responsiva, moderna e organizada.

O site apresenta informações sobre a estudante, projetos desenvolvidos, habilidades e um formulário de contato.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- Unsplash para imagens
