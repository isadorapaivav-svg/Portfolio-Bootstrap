# 💻 Portfólio Pessoal — Bootstrap 5

## 📌 Sobre o projeto

Este projeto foi desenvolvido como **atividade prática do curso de Bootstrap 5 da plataforma Cursa**.

O objetivo é aplicar, na prática, os principais conceitos apresentados durante o curso, utilizando o framework **Bootstrap 5** para desenvolver uma página de portfólio pessoal moderna, responsiva e organizada.

O portfólio apresenta informações sobre a estudante, projetos desenvolvidos, habilidades e uma seção de contato.

---

## 🎯 Objetivos

- Praticar o desenvolvimento de interfaces utilizando Bootstrap 5.
- Aplicar o sistema de Grid para criar layouts responsivos.
- Utilizar componentes e classes do Bootstrap.
- Desenvolver uma página adaptável para diferentes tamanhos de tela.
- Aplicar conceitos de tipografia, cores, espaçamento e imagens.
- Criar uma interface organizada e visualmente agradável.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons
- JavaScript
- Unsplash para imagens

---

## 📚 Recursos do Bootstrap 5 utilizados

O projeto utiliza diversos recursos estudados durante o curso.

### Grid System

Foi utilizado o sistema de Grid do Bootstrap para criar um layout responsivo.

Classes utilizadas:

- `.container`
- `.row`
- `.col-*`
- `.col-sm-*`
- `.col-md-*`
- `.col-lg-*`

O layout se adapta a diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.

### Navbar

Foi utilizada uma Navbar responsiva para facilitar a navegação entre as seções do portfólio.

Classes utilizadas:

- `.navbar`
- `.navbar-expand-lg`
- `.navbar-dark`
- `.bg-dark`
- `.navbar-toggler`
- `.navbar-collapse`
- `.nav-link`

### Cards

Foram utilizados Cards do Bootstrap para apresentar os projetos desenvolvidos.

Cada card possui:

- Imagem;
- Categoria;
- Título;
- Descrição;
- Botão de ação.

### Botões

Foram utilizados diferentes estilos de botões do Bootstrap:

- `.btn`
- `.btn-primary`
- `.btn-outline-primary`
- `.btn-outline-dark`
- `.btn-outline-success`
- `.btn-outline-warning`
- `.btn-lg`

### Formulário

Foi criada uma seção de contato utilizando os componentes de formulário do Bootstrap.

Foram utilizados:

- `.form-label`
- `.form-control`
- Botões;
- Campos de texto;
- Campo de e-mail;
- Área de mensagem.

### Cores

Foram utilizadas classes de cores do Bootstrap, como:

- `.bg-dark`
- `.bg-light`
- `.text-primary`
- `.text-secondary`
- `.text-white`
- `.text-bg-primary`
- `.text-bg-success`
- `.text-bg-warning`

### Tipografia

Foram utilizadas classes de tipografia do Bootstrap:

- `.display-3`
- `.display-6`
- `.lead`
- `.fw-bold`
- `.fw-semibold`

### Espaçamento

Foram utilizadas classes de margem, preenchimento e espaçamento:

- `.mt-*`
- `.mb-*`
- `.py-*`
- `.p-*`
- `.g-*`

### Imagens

Foram utilizadas classes do Bootstrap para configuração e responsividade das imagens:

- `.img-fluid`
- `.rounded`
- `.rounded-circle`
- `.shadow`

---

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela.

O Bootstrap 5 é utilizado para adaptar a estrutura das seções, colunas, cards, formulário e menu de navegação.

Também foi utilizado CSS personalizado com `@media` para realizar ajustes específicos em telas menores.

O portfólio pode ser visualizado em:

- 💻 Computadores
- 📱 Smartphones
- 📲 Tablets
